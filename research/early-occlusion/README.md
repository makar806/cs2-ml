# Раннее обнаружение игроков за укрытием

Хэндоф от 18 ноября 2026 года. Исследование использует сохранённые кадры игры CS2. Цель — выделить видимый фрагмент игрока на первом различимом кадре, пока остальная часть тела закрыта укрытием.

## Порядок чтения

1. [Минимальный промпт](PROMPT.md) задаёт цель для нового агента.
2. [Результаты и причины выбора](FINDINGS.md) описывают версии, ошибки и границы доказанного.
3. [Индекс измерений](EVIDENCE.md) связывает с конкретной разметкой, весами и отчётами. Общий хэндоф от 10 ноября в корне репозитория даёт исторический контекст проекта.

Ветка основана на `handoff/2026-11-10`. Исследование находится целиком в этой папке. Для воспроизведения приложены веса V18 и V19, 45 коротких роликов и разметка. Из отрывков удалено аудио, видеопоток обрезан без перекодирования. Все 1 246 необходимых кадров побайтно совпали с оригиналами после декодирования OpenCV. Источник и условия использования описаны в карточке набора. [OpenCS2, CC BY 4.0](https://huggingface.co/datasets/blanchon/opencs2_dataset#licensing)

## Запуск сравнения

Исходные проверки выполнялись на Windows с Python 3.11, CUDA 12.8, RTX 4060 Laptop 8 ГБ, Intel i7-12700H и 16 ГБ RAM. Версии Python-пакетов зафиксированы для воспроизведения. Для установки PyTorch выбери дистрибутив под доступное устройство. Поддерживается `--device cpu`, его результаты и задержки следует записывать отдельно от CUDA FP16.

```bash
git clone --branch handoff/early-occlusion-2026-11-18 --single-branch https://github.com/makar806/cs2-ml.git
cd cs2-ml/research/early-occlusion
python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements.txt
python src/verify.py
python src/replay.py --checkpoint v18 --motion --device cuda --output replay-v18.json
python src/verify.py --replay replay-v18.json
python src/replay.py --checkpoint v19 --benchmark previous --device cuda --output replay-v19.json
```

Прогон читает короткие ролики из `data/media` и проверяет SHA-256. По умолчанию результаты пишутся в `replay-result.json`. Пропавший или повреждённый отрывок можно восстановить из оригинала по URL и SHA-256 из манифеста. Если веса нового кандидата совместимы с выходом V18, передай свой путь в `--checkpoint` и зафиксируй `--confidence` по отдельной калибровке. На CPU расчёт займёт дольше. Для отчёта о времени сохраняй устройство и параметры, с которыми сделан замер.

## Подготовка следующего кандидата

Для переобучения используй V18 как стартовые веса. Снимки исходного полного обучения V18/V19 остаются в локальной коллекции. Публичные кадры с ручной разметкой для эксперимента V19 лежат в этом комплекте. [Схема разметки и веса](EVIDENCE.md)

```bash
python src/export-calibration.py /path/to/exported-training-additions
python src/train-candidate.py /path/to/new-dataset.yaml --project /path/to/output
```

Экспорт даёт только добавку к обучению. В новом `dataset.yaml` укажи отдельные `train` и `val` из разных матчей, `names` с `0: T` и `1: CT`, `kpt_shape: [1, 3]` и `flip_idx: [0]`. Ветка содержит все кадры и веса для повторения проверок на отрывках. Полный исходный датасет для обучения с нуля потребуется отдельно.
