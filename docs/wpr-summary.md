# Выжимка из двух трасс WPR

Оба прогона сравнивали игру без захвата и с одним DXGI-захватом. Инференс и управление для сравнения не требовались. Длинный кадр здесь означает интервал между Present свыше 100 мс по CSV PresentMon.

| Прогон | Без захвата | С DXGI | Пик RAM, без / с захватом | Потеряно событий WPR |
|---|---|---|---|---:|
| 8 ноября, 23:48 | 0 длинных, максимум 26,7 мс | 4 длинных: 305,6; 256,9; 518,2; 484,0 мс | 83,1% / 83,5% | 18 106 235 |
| 9 ноября, 02:42 | 3 длинных: 181,7; 269,2; 104,6 мс | 1 длинный: 152,4 мс | 96,6% / 96,7% | 2 539 727 |

В первом прогоне DXGI-этап дал четыре длинных кадра двумя парами. Во втором три из четырёх длинных кадров пришлись на этап без захвата. Сеансы отличаются условиями и их нельзя объединять как повтор одного эксперимента.

В извлечённых окнах сохранились графические события, но в обоих файлах поле `render_switches` пустое. Это пробел наблюдения. По нему нельзя установить, ждал ли поток вывода игры планировщик, GPU, драйвер или другую операцию. Вторая запись также проходила при гораздо более высокой занятости RAM. Трассы подтверждают время и контекст пауз, а причинный механизм остаётся гипотезой.

Машиночитаемое подтверждение есть в `summary.json`, `freeze-events-fast.json`, `wpr.log` и `present.csv` соответствующих этапов `20261108-234836` и `20261109-024200`. Полные ETL для работы с этой выжимкой не нужны. Если вывод требует событий вне выбранных окон, попроси конкретное извлечение из локального ETL. [Индекс остальных замеров](measurement-index.md).
