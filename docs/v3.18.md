# v3.18 — зона выстрела, период 250 мс, упреждение

## Изменение поведения

Новый ZoneController применяется из GUI по умолчанию. Фильтр по умолчанию 1€. Список «Текущий / 1€» остаётся. Предыдущий RecordedController сохранён как исследовательская база, но GUI использует новый режим.

### Зона

Центр круговой зоны — исходная выбранная моделью точка, компенсированная оценкой движения цели за фактический возраст кадра. Радиус для головы: max(0.5*width/1280, min(body_width*.14, body_height*.055)). Это геометрическая оценка размера головы, не обученная head-box модель и не хитбокс игры. Для вручную выбранного корпуса: min(body_width*.22, body_height*.12) с тем же нижним ограничением.

Внутри круга прекращаются коррекции. Разрешение первого выстрела не ждёт двух наблюдений, критерия минимального остатка фильтра или окончания плавного отрезка. Остаются валидность/порог детекции и точки, свежесть источника (100 мс), фокус игры, F8/F9 и отсутствие потери удержания. Без валидной цели или после истечения возраста старая серия прекращается. Амодальное восстановление не используется.

### Интервал

250 мс отсчитываются от фактической успешной отправки прошлого выстрела. Планировщик проверяет готовность независимо от прихода нового кадра и окончания траектории, используя только свежую зону. Бюджет «один выстрел на удержание» убран в новом режиме. После пропуска/паузы нет догоняющей очереди выстрелов. Интервал в GUI фиксирован; рандомизации нет. Windows/API, потеря зоны, устаревание источника или остановка WASD могут увеличить фактический интервал: это не генератор случайных задержек и не обещание жёсткого real-time.

Остановка WASD перед первым выстрелом сохраняет выдержку 180 мс и теперь имеет отдельную галочку. Для немедленной отправки при входе в круг её можно отключить и снова запустить мониторинг. Тогда автоматической остановки движения не будет. Для уже стоящего игрока выдержка не добавляется. Клавиши для ходьбы пока стандартные WASD.

### Плавность и прогноз

Для нового режима личный профиль не загружается и не используется. HeadFilter/1€ дают оценку скорости; упреждение учитывает возраст текущего кадра и будущий отрезок коррекции (до 60 мс). Экстраполяция ограничена масштабом тела. Движение использует затухающую коррекцию с постоянной 70 мс и подачей оценённой скорости, с ограничением шага текущей прогнозируемой конечной точкой. Новый монотонный отрезок не может пройти дальше запрошенного конца. Это исправляет источник возможных перелётов в законе управления, но не гарантирует отсутствие перелёта при неверном FOV/zoom, шуме головы, ручных движениях и задержках камеры.

Повторно записывать человеческое наведение для этого изменения не требуется. Предыдущий профиль определял время, а не копировал промахи или траектории пользователя.

### RAM

memory_guard=False по умолчанию. При 95–98% RAM нет программной паузы по старому порогу свободной памяти. Галочка в GUI позволяет вернуть защиту (600 МБ остановка, 900 МБ возобновление). Настройка применяется при запуске мониторинга. Реальная ошибка выделения памяти остаётся возможной; снятие порога не создаёт свободную память.

### Визуализация

Галочка «Показывать зелёную зону» управляет отдельным прозрачным окном с контуром. Оно не принимает клики и фокус; нет захвата/инъекций через графический API. Зона скрывается при паузе, потере фокуса/цели или устаревании кадра. Видимость в эксклюзивном полноэкранном режиме зависит от Windows/режима игры. Настройки игры не менялись. Визуализация 20 Гц, запись status.json ограничена 4 Гц. Управляющая зона вычисляется отдельно в высокочастотном цикле и не зависит от частоты отрисовки.

## Проверки

Новый набор проверяет первый выстрел по одному свежему кадру, период 250 мс без ожидания следующего кадра, F9, потерю/старение цели, уменьшение радиуса с расстоянием через размер рамки, сохранение глобального интервала при сбросе, упреждение по возрасту/горизонту, отключение RAM-паузы, отключение остановки WASD и свойства окна (click-through/no-activate). В синтетических неподвижных сценариях offset=80/250/450, age=30/70 мс нет пересечения центра дальше 0.5 px.

Расширенный benchmark: 36 случаев (offset 80/250/450, speed 0/60/180, delay 30/70 мс, 20/30 Гц, шум .5 px), все дают выстрелы, минимум 6 за 3 секунды, минимальный интервал .25 с. Максимальная фактическая ошибка выстрела в симуляторе 8.04 px, то есть попадание в расчётную зону не гарантирует попадание в настоящую голову. Это результат синтетического теста, не точность CS2. Файл work/zone-benchmark-v318.json.

Игровая проверка новой версии не выполнялась. Не утверждать, что фризы, ошибки предсказания или перелёты устранены. Изменения не опубликованы в GitHub. Резервная копия исходников v3.17: work/backup-v317-zone. SAMEO отложен по прямому указанию пользователя; GSI не включался.
