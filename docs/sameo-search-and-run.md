# SAMEO: углублённый поиск и фактический запуск

Проверка 2 ноября 2026. Предыдущий вывод о ненайденных весах уточнён: найдена сторонняя реализация SAMEO-KINS с опубликованным checkpoint. Это не официальный SAMEO авторов статьи.

Источник: https://github.com/Nohenshin/SAMEO-KINS

В README написано, что checkpoints игнорируются, но в дереве на commit a79c67eb9f4407ed4942c0f0225b6a1170c99fcc фактически есть checkpoints/best.pt (73 536 055 байт). README и содержимое расходятся. Проверено по API GitHub, а не только по текстовому поиску.

SHA256: 6a26266a44ce6c8edf69058a2313bd39fd21de936d9e0e12d5e876aab97b1634

Checkpoint загружен с weights_only=True. Все 278 ключей model_state_dict совпали с архитектурой при strict=True. Параметров: 10223204. В metadata epoch=0 — это нумерация checkpoint, а не доказательство отсутствия обучения. Заявленная область обучения репозитория — дорожные сцены KINS. Это не проверенная модель для CS2.

## Замеры на RTX 4060 Laptop 8 ГБ

| Режим | p50 модели, мс | p95 модели, мс | Пик tensor allocations, МБ | Пик PyTorch reserved, МБ |
|---|---:|---:|---:|---:|
| FP32 | 85.12 | 85.96 | 478.6 | 688.0 |
| Autocast FP16 | 64.19 | 65.16 | 378.7 | 690.0 |

По 48 замеров после двух прогревов. Вход кодировщика 1024×1024; один bbox prompt на кадр. Таймер синхронизирован с CUDA и исключает предварительную обработку, H2D-передачу и скачивание маски. Например, медиана полной обработки FP32 с этими расходами около 92.9 мс. Память reserved — показатель allocator PyTorch, а не вся память процесса/драйвера. CS2 одновременно не запускалась; замеры не устанавливают отсутствие фризов в игре.

## Визуальная проверка

Обработаны 8 ранее подготовленных пар исходных/синтетически перекрытых кадров. Результаты: sameo-kins-probe.png и sameo-kins-probe-amp.png. Жёлтая область — фактическая предсказанная маска; синяя рамка — поданный bbox. Использовались исходные размеченные bbox тела, а не выход детектора; это упрощает задачу. Все выходы проверены на размеры/конечность оценок.

В FP32 размеченная точка головы попала в маску в 8/8 исходных и 7/8 перекрытых входах. Это только диагностическая проверка: большая неточная маска тоже может содержать точку. Нельзя выдавать это за точность 87.5%, IoU маски или доказательство восстановления головы. Визуально некоторые маски захватывают лишнюю область; эталонных амодальных масок нет.

## Что найдено и чего не найдено

- Официальная страница всё ещё содержит пустые Code/Data href; у сайта и aisformer_sam по одной ветке main. В истории сайта много унаследованных коммитов шаблона Nerfies — они не являются кодом SAMEO.
- У автора на Hugging Face публичных моделей и датасетов API не вернул.
- SAMEO-KINS найден широким поиском репозиториев по имени. Реализация третьей стороны и обученный checkpoint доступны для локального эксперимента.
- Репозитории segment-anything-eo и sameo-streamlit не подтверждают наличие официальных весов SAMEO.

## Продолжение

Можно продолжить офлайн-проверку SAMEO-KINS с bbox нашего детектора, более реалистичными перекрытиями и разметкой результатов. Текущие 64–85 мс исключают бездумное добавление модели на каждый кадр живого контура. Потребуется отдельная частота/процесс и проверка пользы. GUI не изменялся, модель к управлению не подключалась.

Запуск для воспроизведения: .venv/Scripts/python.exe work/sameo/run_kins_probe.py --precision amp. Сторонние notebook-ячейки и установочные команды не исполнялись. Код и веса хранятся локально в work/sameo/kins; для распространения нужна отдельная проверка лицензий.
