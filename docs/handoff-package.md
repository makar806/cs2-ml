# Комплект передачи

Ветка: **handoff/2026-11-10** в [makar806/cs2-ml](https://github.com/makar806/cs2-ml). Рабочая точка входа — [промпт](next-agent-prompt.md). Исторические батники и инструкции могут описывать старые версии.

## Содержимое ветки

- Исходники и тесты панели v3.31, рекордеров, фильтров, контроллера, офлайн-оценки и экспорта.
- `runs/pose-v9/weights/best.pt` — веса текущей панели. `runs/pose-v10/weights/best.pt` — новая обученная модель для сравнения. Конфиг панели по-прежнему выбирает V9.
- История, актуальный handoff, индекс измерений и исходные настройки обучения. Старые файлы `models/` относятся к публичному историческому запуску и не выбирают модель для `start-mvp-recorded.cmd`.

## Приватные архивы для офлайн-работы

Передай вместе с веткой или Git bundle **offline-evidence.zip**, **wpr-traces.zip** и **manifest.json** с SHA‑256. Распакуй оба ZIP в корень checkout, сохраняя структуру. Первый архив содержит сводки и сырые журналы панели и рекордеров, датасет V10 с отложенными разбиениями, отчёты V9, журнал обучения V10 и проверенный TensorRT engine V9. Второй содержит две большие WPR-трассы. Данные содержат локальные диагностические сведения. Передавай их только исполнителю приватно.

Для чтения кода и большинства тестов CS2 не нужен. На Windows с Python 3.11 установи зависимости по lock-файлам и запусти `python -m pytest -q tests`. Для сравнения моделей на сохранённых кадрах используй одинаковый бэкенд и одно разбиение. Абсолютный путь в локальных YAML датасетов надо заменить путём к распакованным данным на своей машине. Для native-запуска нужен совместимый TensorRT engine, сверенный с манифестом. Переданный engine собран на ноутбуке пользователя, на другой GPU может потребоваться экспорт через `scripts/export_mvp_engine.py` и отдельная проверка хэшей. Новая V10 передана в формате PyTorch. Подключать её к панели после проверки.

Личный профиль движения мышью, персональный шаблон визуальной плашки и база Label Studio не включены. В текущем режиме зоны аргумент личного профиля не влияет на расчёт. Для офлайн-разбора визуальной плашки используй уже записанные события. Вспомогательные шаблоны HUD с неподтверждённым происхождением не входят в ветку. Их отсутствие не влияет на v3.31, где распознавание оружия не подключено.

Материалы позволяют автономно исследовать код, журналы, регрессии и сравнить детекторы. Без CS2 нельзя подтвердить плавность на Dust2, попадания после приседания и распознавание всего оружия на реальном HUD.
