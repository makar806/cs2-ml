# MVP v3.1: удержание цели и темп стрельбы

Выбор ближайшего к прицелу противника каждый кадр заменён удержанием выбранного.
Сопоставление использует расстояние головы, пересечение и масштаб рамки,
компенсирует отправленный поворот камеры. Радиус первоначального захвата
не применяется повторно к уже удерживаемой цели. При отсутствии соответствия
в течение 0.30 секунды движения/стрельба приостановлены; затем возможен новый захват.
Потеря фокуса, F8 и устаревшие наблюдения сбрасывают состояние контроллера.
Это геометрическая ассоциация, не гарантия идентичности при полном перекрытии.

Интервал нажатий увеличен с 0.12 до 0.40 секунды. Первый выстрел остаётся
немедленным; сопровождение головы между нажатиями продолжается. В панели
добавлена настройка интервала. После изменения требуется перезапуск мониторинга.
Восстановление точности оружия, отдача и вероятность попадания не измерялись.

16 тестов прошли: прежние проверки контроллера/ввода и пять новых сценариев
удержания, пропадания/возврата цели, движения камеры, выхода за радиус захвата
и интервала между выстрелами. Реальная игровая точность этой версии ещё не измерена.

Полный экран без фризов остаётся нерешённым требованием. Код захвата не менялся;
оконный режим — временная проверенная конфигурация. Нужен отдельный замер
frametime одинаковой сцены в fullscreen без MVP, с capture-only и с inference,
чтобы отделить влияние захвата, вычислений и конфигурации вывода изображения.
