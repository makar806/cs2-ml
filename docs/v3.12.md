# v3.12 — experimental visual correspondence
Tracks local appearance including background at 1/8 resolution, up to 10 previous detections, with correlation >= .82 and unique-peak margin .05. Source timestamps must match the last accepted target reference. Rebase into current input coordinates occurs exactly once using MotionHistory. No extra capture or GPU model. Ambiguous or stale image matches fail closed. Visual correspondence is heuristic and requires real scene validation; scale changes, occlusion and repeated textures can reject it.
Kill-feed polling changed from 100 to 33 ms, retaining two-observation confirmation. This reduces sensor delay, not the physical rendering delay. No claim of zero latency or fixed stutter.
137 tests passed including large camera movement with one body, unrelated replacement frame and stale image rejection. Backup: work/backup-v311. Live validation pending.
