# Первое обучение CS2 T/CT + голова — 18 октября 2026

YOLO11n-pose дообучен на RTX 4060 Laptop 8 ГБ, 60 эпох, размер входа 640,
batch 8, seed 42. Обучение успешно завершилось. Это первый baseline, не готовый агент.

Разметка ML_CS: 63 изображения, 108 T, 53 CT, 161 точка головы.
Перед обучением проверены связи Head→bbox, диапазоны координат,
размеры оригиналов 1440×1080 и отсутствие точных дубликатов.
Визуально проверена обучающая мозаика после преобразования координат.
Проверены импорты, вычисление CUDA, загрузка датасета, обучение и inference сохранённых весов.
Конвертер не изменяет базу Label Studio.

Разделение по хронологическим сценам: train 45 / val 6 / test 12.
Это не независимые игровые сессии: карты, фон, внешний вид персонажей коррелируют.
Результаты предварительные; test нужно сохранять неизменным, а для дальнейшей
итоговой оценки собрать новую сессию. Test не использовался для выбора эпохи.

## Результаты на 12 test-кадрах

- 25 размеченных персонажей.
- При confidence≥0.25 модель выдала 13 рамок.
- 7 рамок правильно сопоставлены с разметкой: совпадает класс и IoU≥0.5.
- Precision: 53.8%, Recall: 28.0%.
- Box mAP@0.5: 0.393; mAP@0.5:0.95: 0.230.
- Средняя ошибка головы: 14.9 пикселя, медиана 10.9 пикселя при 1440×1080.
  Это только 7 правильно сопоставленных персонажей; пропуски сюда не входят.
- Встроенный Pose mAP@0.5: 0.480; нормировка OKS стандартная для custom keypoints.

Precision/recall из Ultralytics могут отличаться: валидатор выбирает другой рабочий
порог и усредняет по классам. В отчёте выше использован явно фиксированный порог.
Встроенное время inference на столь малом наборе не является benchmark FPS или
end-to-end задержки, поэтому выводов о real-time скорости пока не делаем.

## Наблюдаемые ошибки

На test 178 модель выделяет фрагмент стены как CT и пропускает персонажей.
На test 184 один CT назван T, при этом второй CT найден правильно.
На test 189 найдены T и точка головы. На ряде других кадров персонажи пропущены.
Числа confidence в визуализации — оценка уверенности модели, не гарантия правильности.

## Следующий шаг

Проверить неоднозначные разметки в дыму: не размечать полностью невидимые тела
и не угадывать голову. Собрать больше CT, разных ракурсов, малых целей и пустых сцен,
особенно фонов, похожих на персонажей. Снять отдельную игровую сессию для независимой
проверки. Текущих данных недостаточно для надёжного наведения и стрельбы.
