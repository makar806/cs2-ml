# Локальный MVP v3.7 — экспериментальная версия

Текущие изменения: захват цели по всему кадру и подтверждение убийства по
экранной плашке, без GSI. Веса не изменялись. Подробности и ограничения:
[control-v3.7.md](control-v3.7.md). Живая проверка v3.7 ещё требуется.

Проверки v3.5 и v3.6 от 26 октября: фризы сохранялись, пользователь сообщил
плохую отзывчивость наведения и стрельбы. Профиль с лимитом 120 FPS не помог.
Версия не объявляется устранением фризов.
Замеры: [stutter-investigation.md](stutter-investigation.md).

Запуск: двойной клик по start-mvp-bots.cmd в папке проекта. Дождись «Готово».
Проверка управления — в симуляторе или локальном матче с ботами.

- F8 включает/выключает управление и распознавание. Захват остаётся работающим;
  frames=0 до первого запуска — нормально. Модель остаётся в памяти.
- F7 — явно отпустить удерживаемую цель и разрешить новый выбор.
- В режиме visual новая собственная плашка убийства после выстрела разрешает
  следующую цель автоматически. Используется текущий шаблон CT-ника и HUD.
- F9 — сопровождение с выстрелом / только сопровождение.
- F6 или «Стоп» полностью останавливают процесс модели.
- Alt+Tab отключает управление. Для возобновления снова нужен F8.

По умолчанию Native TensorRT без torch/Ultralytics, вход 960, до 30 Hz,
DXGI, игрок CT, противник T, sensitivity 0.97, интервал выстрелов 0.40 секунды.
Чувствительность в игре и панели должна совпадать. Галочка плавности включена.
Настройки применяются кнопкой «Запустить мониторинг»; управление заново включается F8.

Неудачный эксперимент v3.6 сохранён как `start-mvp-balanced.cmd`, но он
не рекомендуется для устранения фризов. В текущем тесте исходный лимит
`fps_max 448.2176` возвращён, экономное ожидание отключено. В CS2 применён
«Полноэкранный в окне», 1920×1080. Первая запись в этом режиме не содержит
кадров >50 мс (максимум 34.87 мс), но фокус был только 94.3% времени, поэтому
полное устранение фризов ещё не подтверждено строгим сравнением.

960 снижает нагрузку, но уменьшает детализацию дальних целей. Для сравнения можно
выбрать 1280. WGC — альтернативный захват, если DXGI не работает на текущем дисплее.
MSS fallback отсутствует. capture/inference — диагностические режимы без ввода;
F8 не включает в них мышь. auto/native выбирают облегчённый runtime; tensorrt и
pytorch оставлены для явного сравнения и используют больше RAM.

В панели видны свободная RAM, рабочий набор модели, чтение страниц с диска,
реальная частота цикла ввода и число созданий захвата. Частота цикла/модели не
равна FPS игры. При критическом недостатке RAM управление останавливается.
Системные настройки, драйверы, службы защиты, файл подкачки не меняются.

Первый захват быстрый. Удержание одной цели сохраняется по рамке/голове с учётом
команд камеры, в том числе при покадровом flip её класса. Новый союзник не может
быть захвачен как враг. Потеря цели приостанавливает ввод без нового выбора;
визуальная плашка собственного убийства разрешает новый выбор; для ручного
сброса есть F7. Это эвристика по kill-feed, а не достоверный world ID смерти.
Одинаковые перекрывающиеся персонажи могут перепутать геометрическое
сопоставление. Первоначальная ошибка T/CT нейросети остаётся ограничением.

Последующие коррекции плавные, с уменьшенным усилением обратной связи. Прогноз
головы ограничен её масштабом, после выстрела подавлен. Повторный выстрел требует
двух наблюдений головы около центра. Интервал 400 мс — минимальный, а не обещание
выстрела каждые 400 мс. Отдача, разброс и ошибки головы по-прежнему могут дать промах.

Для обычной игры закрывай панель или нажимай «Стоп». Симулятор запускается через
start-mvp-simulator.cmd; перед ним закрой панель локальных ботов или выбери режим
simulator (sensitivity=1). Это функциональный стенд, не оценка hitbox/точности игры.

Логи: runs/live-mvp/<время>/status.json, settings.json, frames.jsonl,
actions.jsonl, control.jsonl, memory.jsonl, error.txt.
Клики в счётчике — запросы ввода, а не выпущенные пули или попадания.

Полный экран без фризов не подтверждён. Последняя запись получала кадры
1920×1080; размер входа 960/1280 в панели
не меняет разрешение игры. Снижение памяти подтверждено, универсальное устранение
фризов и исправление качества нейросети не заявляются.

Отчёт: [mvp-v3.4.md](mvp-v3.4.md).
