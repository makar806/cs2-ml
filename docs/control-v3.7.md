# Управление v3.7: весь кадр и визуальное подтверждение убийства

Пользователь подтвердил исчезновение фризов после перехода CS2 в
«Полноэкранный в окне», 1920×1080. Эти настройки в v3.7 не менялись.
Нейросетевые веса V7, размер входа 960, Native TensorRT и DXGI сохранены.
Проверка ввода предназначена для отдельного симулятора или локальных ботов.
Безопасность аккаунта в античитах не гарантируется.

## Исправления управления

- Радиус первоначального захвата 260 px (масштабируемый по ширине) заменён
  полным кадром: Settings.radius=0. Положительный радиус остаётся opt-in.
- Лимит одной команды 4096 counts позволяет повернуться к видимой цели у края
  за одну коррекцию; явные ограничения шага и запрет выстрела при clamp сохранены.
- Ассоциация цели и пересчёт изображения в полёте используют перспективную
  модель поворота камеры. Старый одинаковый сдвиг всех пикселей не учитывал
  изменение масштаба тела после большого поворота и мог нарушить scale gate.
- Почти совпадающие T/CT-рамки одного тела не считаются двумя разными кандидатами
  при удержании. Две геометрически неоднозначные разные цели по-прежнему дают паузу.
- Удержание не снимается из-за таймаута отсутствия рамки. F7 — явный ручной сброс.

## Визуальный сигнал

По умолчанию --death-source visual. GSI не устанавливался в игру и в этом
режиме не запускается, даже если его конфиг когда-либо появится отдельно.

Калибровка ника сделана по существующему кадру
data/pose-v1/images/train/127_20261017190449.jpg. Бинарный шаблон находится в
work/killfeed/self-name.png. Используется CT-цвет имени слева в выделенной
красной рамке kill-feed и жёлтое имя жертвы справа. Это специализированный
вариант для текущего CT/HUD/ника, а не универсальное распознавание текста.

Парсер получает тот же кадр, что и детектор. Дополнительного захвата экрана,
OCR, GPU-модели и игрового канала данных нет. Небольшой участок справа сверху
обрабатывается до 10 раз в секунду; нужны два последовательных наблюдения
изменения списка. При F8 off старые плашки становятся baseline и не считаются
новыми после включения. Перемещение старой строки не считается новым убийством.
Сигнал используется только после недавнего выстрела текущего контроллера.

После подтверждения сбрасывается только identity, а 400-мс ограничение темпа
выстрелов сохраняется. Новая цель может получать наведение сразу после сигнала,
не ожидая окончания оружейного интервала. На следующем свежем кадре остаточная
анимация прежнего тела кратко исключается геометрически (0.4 с).

Ограничения: скрытый kill-feed, изменение ника/масштаба/цвета HUD, нечёткая
плашка, полностью одинаковый насыщенный список повторных убийств могут дать
пропуск. Собственный kill-feed не даёт world ID убитого; при ручном убийстве
другого противника, пока контроллер держал прежнего, возможна неверная ассоциация.
Поэтому точность/гарантия удержания до смерти не заявляется. F7 остаётся запасным
способом отпустить цель. Исчезновение рамки само по себе смертью не считается.

## Проверка

85 тестов прошли: в том числе края кадра, сохранение identity после большого
перспективного поворота, собственная смерть/чужое убийство, старый banner при F8,
повторы жертвы, scrolling, исчезновение на один кадр, потеря фокуса, cooldown
и ожидание окна игры без инициализации DXGI на неподдерживаемом рабочем столе.

На одном сохранённом изображении распознаны все три видимые яркие собственные
строки. Парсер: медиана 5.55 мс, p95 6.18 мс на 100 повторениях того же кадра.
Это microbenchmark, не оценка precision/recall или влияния на FPS в CS2.
Веса не переобучались, оценка качества детекции не менялась и не пересчитывалась.
Живая игровая проверка v3.7 ещё не проведена: CS2 в момент запуска новой панели
была закрыта. Автоматические тесты не вводили мышь в Windows.

На закрытой CS2 первый запуск выявил DXGI_ERROR_UNSUPPORTED при подготовке
захвата рабочего стола гибридного ноутбука. Worker теперь ждёт окно целевой
игры до создания устройства захвата. Переходы F8 и Alt+Tab после создания
устройства по-прежнему не пересоздают его.

Запуск: start-mvp-bots.cmd. Для текущей проверки игрок CT, death-source visual,
F8 включает, F9 меняет стрельбу/только наведение, F7 отпускает, F6 останавливает.
В status.json записываются visual_feed_rows, visual_feed_ms,
visual_kill_sequence и confirmed_kill_releases. В control.jsonl есть отдельное
событие visual_kill_confirmed.
